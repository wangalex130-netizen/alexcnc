# App 体验优化审计（UI / 交互 / 性能 / 信息）

> **日期**：2026-08-10 ｜ **范围**：alexcnc Flutter App 消费端（图库 / 详情页 / 向导 6 步 / 自检 / 监控 / 控制台）
> **目标**：运行流畅丝滑；美观大气简约；信息清楚；交互优化。
> **原则**：只动消费端自己的文件；摄像头两文件（rtsp_preview_widget / camera_discovery）禁区；不改已锁定协议。
> 优先级：P0=体验卡点 ｜ P1=明显提升 ｜ P2=打磨。

---

## 一、流畅丝滑（性能）

| # | 现状依据 | 问题 | 建议 | 优先级 |
|---|---------|------|------|:---:|
| P1-1 | 图库灵感库用 `GridView(shrinkWrap)+NeverScrollable` 嵌在 SliverList | 模型多时**一次性构建全部卡片**，滚动掉帧 | 改 `SliverGrid`（懒加载，可视区才构建） | P0 |
| P1-2 | 卡片图片直接 `Image.network` 无统一封装 | 无骨架占位、加载闪白、失败无兜底、无内存缓存策略 | 抽统一 `_img()`：loadingBuilder 骨架 + errorBuilder 兜底 + `cacheWidth` 降内存 | P1 |
| P1-3 | 监控页 `AnimatedBuilder(_head)` 每帧重绘整个 `CustomPaint`（刀路数千段） | 呼吸点动画拖着重绘全部刀路，帧率不稳 | 呼吸点独立小 widget；刀路层用 `RepaintBoundary` 隔离，仅 progress 变化时重绘 | P1 |
| P1-4 | 监控页 `Timer.periodic(1s) → setState` 全页重建 | 每秒重建整页（含刀路/摄像头），浪费 | 计时只影响 `_elapsed` 一个数字 → 局部状态/ValueNotifier | P2 |
| P1-5 | 页面跳转全部默认 `MaterialPageRoute` | 无过渡动画，"生硬" | 关键路径加 `Hero`（卡片封面→详情大图）+ 转场微调（150-250ms ease） | P2 |
| P1-6 | 列表项未全部 `const`/无 `RepaintBoundary` | 重建开销 | 叶子组件 const 化 + 卡片包 RepaintBoundary | P2 |

## 二、美观大气简约（视觉）

| # | 现状依据 | 问题 | 建议 | 优先级 |
|---|---------|------|------|:---:|
| V1-1 | 令牌已有（bg 浅灰/panel 白/card 白/primary 荧光绿/primaryInk 深绿/border） | 颜色体系已统一 ✅ | 保持；**绿只做强调**（选中/主按钮/高亮），大面留白 | — |
| V1-2 | 字号/间距零散（10~30px 混用、间距 4~16 随手） | 层级感弱 | 立**字号体系**（title 17 / body 14 / caption 12，最小 11）+ **8px 间距网格** | P1 |
| V1-3 | 卡片按压无统一反馈 | 点击"硬" | 统一 `InkWell` 水波纹 + 按压 0.98 缩放（150ms） | P1 |
| V1-4 | 空态/错误态为纯文字 | 冷清 | 补**轻插画/图标 + 引导文案 + 动作按钮**（图库空→去灵感库；断连→重试） | P1 |
| V1-5 | 底部 Tab 选中态 | 已有点色，可增强 | 选中图标+文字同色联动 + 微缩放 | P2 |
| V1-6 | 详情页参数网格为文字块 | 信息平铺 | 图标化 + 大数字（尺寸/时长醒目），弱化标签 | P2 |

## 三、信息清楚（可用性）

| # | 现状依据 | 问题 | 建议 | 优先级 |
|---|---------|------|------|:---:|
| I1-1 | DRO/进度已用 monospace 等宽数字 ✅ | — | 保持并推广到时长/坐标全场景（数字对齐不跳动） | — |
| I1-2 | 状态色令牌齐全（primaryInk/warning/danger/blue） | 部分场景硬编码色（如 `Color(0xFFF5F7FA)` 占位底） | 统一用令牌；占位底并入 `panelAlt` | P2 |
| I1-3 | 10px 小字存在 | 浅底可读性临界 | 最小字号提到 11-12px；次要信息用 textSub 而非缩小字号 | P1 |
| I1-4 | 卡片信息多字段平铺 | 主次不分 | **三层信息分层**：标题(粗) → 关键参数(中等) → 标签(灰小) | P1 |
| I1-5 | 错误提示形态不一（页面内/无） | 用户不知出错 | 统一 snackbar/toast + 关键操作（开切/调平）失败可"重试/查看详情" | P1 |
| I1-6 | 步骤指示器已做（done/active 绿灰）✅ | — | 保持；步骤标题旁可加"1/6"计数 | P2 |

## 四、交互优化

| # | 现状依据 | 问题 | 建议 | 优先级 |
|---|---------|------|------|:---:|
| X1-1 | 向导 6 步直接切换 | 无过渡 | 步骤间 `AnimatedSwitcher`（滑动+淡入 200ms） | P1 |
| X1-2 | Jog 单次点击 + 步距选择 | 连续移动要反复点 | **长按连续点动**（repeat）+ `HapticFeedback.lightImpact()` 振动反馈 | P1 |
| X1-3 | 加载统一转圈 | 等待感强 | 骨架屏（卡片/网格 skeleton）+ 首次加载后本地缓存 | P1 |
| X1-4 | 删除有确认 ✅ | — | 保持；补"撤销"（snackbar action）体验更佳 | P2 |
| X1-5 | 监控页/详情页无下拉刷新/重试入口 | 断连只能等 | 状态卡加"重试"按钮（已部分有）→ 统一化 | P2 |
| X1-6 | 参数修改无"恢复默认" | 改错要手动还原 | 材质/刀具/调平参数卡加"恢复推荐值" | P2 |

## 落地节奏建议

- **第一批（P0+P1 高价值，可先做）**：
  1. 图库 `SliverGrid` 化 + 统一图片组件（P1-1/P1-2）——最直接的"丝滑"提升
  2. 统一字号/间距体系 + 卡片按压反馈（V1-2/V1-3）——"大气简约"
  3. 向导步骤过渡 + Jog 长按连发（X1-1/X1-2）——"交互优化"
- **第二批（P1 其余）**：空态插画、骨架屏、错误提示统一、信息分层
- **第三批（P2）**：Hero 转场、局部刷新、恢复默认等打磨
