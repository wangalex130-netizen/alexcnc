# 本地联调指南（无硬件也能跑通 App ↔ 固件全链路）

> 适用：嵌入式工程师不在、或手边没有真机时，用本机模拟「云端 + Broker + 固件」，
> 让手机 APK 一键联调演示。验证通过的契约见 `docs/PROTOCOL.md`。

## 1. 组件与端口

| 组件 | 文件 | 端口 | 作用 |
|------|------|------|------|
| Mock 云端 | `server/server.py` | 8787 | 材质主表 / 任务元数据 / G-code 推送（REST） |
| 本地 MQTT Broker | `server/local_broker.py` | 1883 | 替代公共 Broker，命令/状态帧中转 |
| 模拟固件 | `server/fake_firmware.py` | — | 扮演 ESP32，订阅 `cnc/<id>/cmd`、广播 `cnc/<id>/status` |
| 链路自测 | `server/mqtt_loopback_test.py` | — | 自动发命令并断言状态帧（无需手机） |

> 真实演示也可直接用公共 Broker `broker.emqx.io:1883`（手机网络不受沙箱限制），
> 量产后再换成自有域名。本地 Broker 仅用于「完全离线 / 无外网」的演示与回归。

## 2. PC 端启动（3 条命令）

依赖：Python 3.10+；模拟固件需 `pip install paho-mqtt`，本地 Broker 需 `pip install amqtt`。

```bash
# 终端 A：Mock 云端
python server/server.py 8787

# 终端 B：本地 MQTT Broker（匿名可连）
python server/local_broker.py

# 终端 C：模拟固件（deviceId 需与手机一致，默认 alexcnc-001）
python server/fake_firmware.py 127.0.0.1 alexcnc-001
```

无手机时，直接跑 `python server/mqtt_loopback_test.py alexcnc-001` 即可看到
`job start → 自检 sc 0/8→8/8 → jog 坐标回显 → leveling → pause/resume/stop` 全链路通过。

## 3. 手机 APK 指向本地（出包参数）

用 PC 的**局域网 IP**（例如 `192.168.1.22`）替换下方地址，出 Real 包：

```bash
flutter build apk --release \
  --dart-define=USE_REAL_BACKEND=true \
  --dart-define=CLOUD_BASE_URL=http://192.168.1.22:8787 \
  --dart-define=MQTT_BROKER=192.168.1.22 \
  --dart-define=DEVICE_TCP_HOST=192.168.1.22 \
  --dart-define=DEVICE_ID=alexcnc-001
```

> 若用公共 Broker 演示：`MQTT_BROKER=broker.emqx.io`，并把 fake_firmware / 手机都连它。

## 4. 预期现象

- App 连接态显示 `connected`（新增 `ConnectionState` 流，断线后自动指数退避重连）。
- 控制台 RTSP 预览显示摄像头裸画面（默认 `rtsp://admin:abc123456@192.168.1.47:554/11`，真机替换）。
- 向导 Step5 调平点数按模型尺寸计算，下发 `setLevelingPlan` 后模拟固件打印网格方案。
- 点「开始雕刻」→ 模拟固件进入 `busy` 并先播自检阶段（`scIndex/scTotal`），再推进进度。

## 5. 给嵌入式工程师的对接清单（必读 `docs/PROTOCOL.md`）

固件侧需实现，App 已按契约对齐：

1. 上电连接 Broker（默认 `broker.emqx.io:1883`，量产后换自有域名）。
2. 订阅 `cnc/<deviceId>/cmd`，解析命令帧：`jog / home / setWorkZero / spindle /
   aux / job(start|pause|resume|stop) / toolMap / leveling`。
3. 周期广播 `cnc/<deviceId>/status`，字段含 `state / pos / mpos / rpm / feed /
   progress / etaSec / scIndex / scTotal / aux / tools`。
4. **自检流水线由固件拥有**：`job start` 后先播自检阶段（App 仅渲染 `scIndex/scTotal`，
   不计时），结束再进加工进度。
5. 调平：`leveling` 帧含 `mode/cols/rows`，由固件执行探点。
6. G-code 由云端直推 MCU，固件不向 App 索取；App 只发 `job start` 触发。

另：机身屏需显示 mDNS 配网配对码，供 App 核对（配网方案已定 mDNS + AP + Token）。
