# App 视觉品牌升级方案 · 对齐 KARVA 机器

> **日期**：2026-08-10 ｜ **触发**：用户提供 KARVA 机器效果图（PANTONE Warm Gray 3 C + PANTONE 2285 C）
> **目标**：让 App 视觉与机器品牌对齐，整体走向"极简、高端、有质感"。
> **原则**：只动 theme.dart / 设计令牌；不改功能与协议。

---

## 一、品牌色源（来自 KARVA 机器）

| 角色 | PANTONE | 近似 RGB（屏幕上观察） | 视觉特征 |
|------|---------|----------------------|---------|
| 主色（外壳） | **Warm Gray 3 C** | `#CCC4BC`（暖灰偏浅） | 中性偏暖、柔和不刺眼 |
| 强调（装饰条 / Start Now） | **2285 C** | `#A3E635`（亮荧光草绿） | 高饱和、活泼但不廉价 |

> ⚠️ 色值为屏幕视觉近似，量产前需用 PANTONE 实物色卡或分光仪校准（品牌色容差 ≤ ΔE 2）。

**机器整体质感**：极简外壳 + 透明罩 + 大留白 + 单一亮绿强调 + 无冗余装饰——典型的 Apple/B&O 高端工业风。

## 三、高端化方向（4 维度，与《App 体验优化审计》互补）

### 1. 字体与间距体系（立规矩）
- **字号**（从大到小）：`title 17` / `subtitle 14` / `body 13` / `caption 12`，最小 11（淘汰 10px）
- **字重**：只用 400 / 600（不再 700，避免过粗；用 600 表达强调）
- **间距网格**：8px（4 / 8 / 12 / 16 / 20 / 24 / 32），现在零散
- **行高**：body 1.5、title 1.3、caption 1.4

### 2. 卡片与圆角（机器风）
- **圆角**：卡片 16、芯片 12、按钮 12、卡片内小元素 8（现在统一 12 偏小）
- **阴影**：克制——`0 1px 2px rgba(0,0,0,0.04)`（主）/ `0 2px 6px rgba(0,0,0,0.06)`（悬浮）。**不放高斯大阴影**（廉价感）
- **卡片底色**：白色卡 + 暖灰底 = "悬浮于桌面"质感（机器透明罩里悬浮部件的感觉）
- **边框替代阴影**：1px 暖描边（`#DCD7D0`）+ 极淡阴影 = 干净有形

### 3. 图标与微交互
- **图标线宽**：1.5px → **1.25px**（更纤细精致；机器上的字 "KARVA" 笔画很细）
- **选中态**：荧光绿底 + 黑字（机器 Start Now 按钮的配色）—— 现在 `CncColors.primary` 已被全用，调好色值即可
- **按压反馈**：0.98 缩放 + 水波纹 + 150ms ease-out
- **过渡**：所有转场 200-250ms `Curves.easeOutCubic`
- **占位/空态**：插画用极简线稿（单色 + 暖灰背景），与机器极简风一致

### 4. 信息层级
- 卡片三层：标题（17/600）→ 关键参数（14/400 primaryInk）→ 标签（12/400 textSub）
- 数字用等宽（monospace）—— DRO/进度/坐标已用 ✅ 推广到时长
- 大数字 + 大留白："尺寸 145×95mm" 比"宽度: 145mm 高度: 95mm"更高端
