# App 用户可见文案 · C 端视角审计报告（2026-09-08）

> 范围：全量 `lib/` 共 72 个 Dart 文件、约 3.4 万行源码中**所有用户可见文字**（页面标题、按钮、空态、错误态、提示、弹窗、SnackBar、hintText、状态标签）。
> 目标：站在「普通消费者」而非「工程师」视角，把生硬、含后台逻辑、含行业黑话的文案，改写为**友好、清晰、有引导性**的表达；统一用「绑定机器」术语。
> 配套改动：本次同时补齐「控制台页三态门控」（未登录 / 未绑定机器 / 正常）。

---

## 一、改写原则（落地口径）

1. **不替客户操心后台**：客户只关心"雕了什么、结果如何、下一步点哪"，不关心接口、档案、G-code、MQTT、设备 ID 等内部实现。
2. **黑话清零**：`MQTT`、`G-code`、`CNC 硬件`、`TCP`、`Spindle`、`Jog`、`联调`、`接口 / 刀库一致性` 等一律改为客户能懂的说法，或删除。
3. **术语统一**：机器与账号的关联一律叫「绑定机器」，按钮叫「去绑定机器 / 扫码绑定」，不再用「添加机器 / 认领档案」等。
4. **引导优先**：空态 / 异常态必须告诉客户"现在该点什么"，而不是甩一句错误原因。
5. **措辞中性**：加工未成功用「未完成」而非「失败」；功能未开放直接说"暂时还不能 XX"，不解释"为什么没开放"。

## 三、本次明确未改的项（及原因）

- **摄像头预览相关文件**（`features/preview/rtsp_preview_widget.dart`、`features/preview/camera_discovery.dart`）：属摄像头调试助理维护范围，主 App 会话只读，按约定不动。其中出现的 `局域网` 等措辞不在本次改写范围。
- **品牌名 `Smart CNC Pro` / `Smart CNC Studio`**：登录页与图库引导里仍在用，与「olduva」品牌是否统一待产品拍板，**不在本任务内**，仅记录待办。
- **调试页内部字段**（MQTT 端口、设备 TCP 端口、设备 ID 等）：本就是给工程师排障用的，保留技术字段；仅把页标题与入口从「联调设置」改为「连接调试」降低困惑。
- **`machines_page.dart:842` 未配置机器码**：属后端异常态兜底文案，出现概率极低且具诊断价值，暂保留。

## 四、验证建议

- 走查路径：未登录 → 控制台（应见"登录后查看机器"）/ 我的（"登录后查看我的机器"）；登录未绑机 → 控制台（"还没有绑定机器"）/ 我的机器（"还没有绑定的机器"）；绑定后 → 正常。
- 雕刻历史删除：后端未开放时提示应为「暂时还不能删除」，不再出现"服务端接口"。
- 联网/断网时控制台顶部状态条显示「云端连接 · 已连接 / 未连接」。
- 需真机/模拟器编译验证 7 个改动文件无语法错误（重点 `_ConsoleGate` 组件与 build 顶部 early-return 的作用域）。
