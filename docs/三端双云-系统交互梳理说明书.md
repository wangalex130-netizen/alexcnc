## 1. 系统概述

### 1.1 一句话

一台桌面 CNC 雕刻机（ESP32 控制 + 机身屏 + 摄像头），由 **手机 App / 电脑端 ArtiMaker / 机身屏**
三个终端共同操作；两台云端服务器（**视频推流** + **状态控制与模型库**）支撑远程访问与三端同步；
内网（局域网）与控制视频直连机器，外网经云端中转。

### 1.2 核心原则（所有实现必须遵守）

1. **ESP32 是唯一真值源（SSOT）**：坐标、刀仓、状态、自检/ATC/调平进度都由机器产生并广播，
   三端只渲染，不裁决、不代传。
2. **资产闭环**：手机/电脑端**永不持有真实 G-code**；G-code 由云端（或局域网伴随服务）
   **直推机器**，App/电脑端只取任务元数据 + 2D 预览矢量。
3. **高级功能归固件**：换刀/对刀/调平/断电续雕等涉及运动安全的序列由**固件拥有并执行**，
   各端只发高级意图（`atc start` / `leveling` / `saveState`）并监听广播。
4. **LAN/WAN 门禁**：内网直连 = 全功能（Jog/回零/开切）；外网 = **监视模式**（锁 Jog/开切，
   仅监控 + 暂停/停止）。
5. **三端不互传状态**：都订阅同一真值；App 与电脑端**不点对点直连**，统一经②同步。

## 2. 参与方与职责

### 2.1 三终端定位

| 端 | 角色 | 核心职责 | 真值源 |
|----|------|---------|--------|
| **机身屏**（机器终端） | **系统核心 / 机器侧 HMI** | 实时显示状态/坐标/进度/报警；**配网（AP + 机器唯一码）**；基础控制（暂停/急停/回零）；断网兜底。**无确认类输入**——远程任务/调平参数下发即执行 | ESP32（同机共享） |
| **手机 App**（alexcnc） | 移动控制/监控端 | 模型库→向导 6 步→控制；实时监控（状态+RTSP+2D 刀路）；远程监视；**按唯一码选择设备**（不做配网） | ESP32/②（本地只渲染） |
| **电脑端**（ArtiMaker） | 设计/切片工作站 + 控制端 | 🎨设计（资源库/AI/2D·2.5D）→ ⚙️生成（一键刀路/3D 预览/切片）→ 🔨制作（控制）；**调平算法与机器端完全一致**；不做配网 | 本地设计/切片；控制与状态来自机器 |

### 2.2 双云服务器职责

**① 视频推流服务器（媒体面）**

| 能力 | 说明 |
|------|------|
| 收流 | 机器把 RTSP 转推上来（RTMP/WebRTC/SRT） |
| 分发 | 外网三端经 HLS（低延迟档）/ WebRTC（实时档）观看；**内网直连 RTSP 不经它** |
| 地址注册 | 推流/播放地址上报②，由②分发给各端 |
| 录播（P2） | 延时摄影、加工回放 |

**② 状态控制 + 模型库服务器（业务面 · 三端同步中枢）**

| 域 | 能力 |
|----|------|
| 设备 | 注册/认证（**机器唯一码** + Token/证书）、在线状态、固件版本 |
| 状态 | 汇聚机器 statusStream 外网中转、报警推送 |
| 命令 | 外网控制转发（监视模式限权） |
| 模型库 | 灵感库、我的空间、历史记录 |
| 任务/G-code | 切片服务、TaskMetadata、**G-code 直推机器** |
| 材质 | 材质参数主表（三端共用 + 本地缓存） |
| 账户 | 登录/注册、**设备绑定（一账号多机，按唯一码）** |
| 诊断 | 日志上报、远程排障 |

### 2.3 已拍板决策（2026-08-06 内部评审）

| # | 决策 |
|---|------|
| D1 | 手机端/电脑端**不做配网**；配网（AP + 唯一码）归**机身屏** |
| D2 | **机器端与电脑端调平算法完全一致**（同一算法双端实现） |
| D3 | 机身屏**无确认类输入**：任务/调平参数下发即执行 |
| D4 | 内网同步按**方案 A（纯云端中枢）起步** |
| D5 | 鉴权按**机器唯一码**；外网 MQTT 加 Token/证书 |
| D6 | **一账号可挂多台机器**，按唯一码选择进入；**暂不支持同时连多台** |
| D7 | **联网与权限模型（2026-08-07 确认）**：所有终端常联网（路由器连外网），机器经机身屏配网后**始终在线**（②注册 + MQTT 长连接）；用户注册账号后输入/扫描唯一码绑定机器；**仅同一局域网可 Jog/开切**，外网只能监视 + 安全操作（暂停/停止/急停） |

### 4.4 关键时序示例

**① 首次绑定（配网 + 唯一码）**
```
开机 → 机身屏进入配网(AP) → 手机连热点 → 输入 WiFi → 机器连网
    → 机身屏显示机器唯一码 → App 输入唯一码 → ② 完成账号↔机器绑定 → 绑定完成
```

**② 内网开始雕刻**
```
App 选模型 → ②返回 TaskMetadata(尺寸/材质/刀具) → 向导 6 步
    → Step5 下发 setLevelingPlan → 开始雕刻 → App 发 job start
    → 机器自检(sc 0→8 广播) → 加工(progress/eta 广播) → 完成
```

**③ 外网远程监视**
```
App 4G → 登录② → 按唯一码选择机器 → ②汇聚状态(1-5Hz) + ①转发视频
    → 监视模式：可暂停/停止，Jog/开切锁定
```

**④ 断电续雕（高级功能）**
```
雕刻中 → 暂停 → 发 saveState → 固件持久化快照 → 断电
    → 上电 → status 带 resumeAvailable → 三端弹恢复入口 → 用户确认
    → 固件回零+恢复G54 → 从断点继续
```

## 4.5 联网与权限模型（2026-08-07 确认）

> 核心事实：**所有终端（机器/手机/电脑）都是联网的**，区别只在"是否在同一个路由器/网段下"；
> 且假定路由器都连外网（所有端理论上都能访问云端）。

- **机器始终在线**：机器经**机身屏配网**（屏幕搜索 WiFi → 输入密码）连上路由器后，向②注册
  （机器唯一码 + 在线状态），并保持 **MQTT 长连接** → 云端随时可见、可下发任务。
- **绑定流**：用户先在手机/电脑注册个人账户 → 通过**输入或扫描机器唯一码**把机器接入自己账号
  （一账号可挂多台，按唯一码选择进入）。
- **"内网"的真正含义 = 控制权差异**：
  - **同一局域网（同一路由器）**：App/电脑端直连机器（TCP:8899），**可以 Jog 点动 / 回零 / 开切**（实时控制）；
  - **4G/5G 或纯外网**：**不能实时控制（锁 Jog / 开切）**，仅**监视 + 安全操作**（暂停 / 停止 / 急停），经②中转。
- 判定方式：App/电脑端 mDNS 或同网段探测 → 同网段 = 全功能；否则走②监视模式。

> 补充两点：①外网仍保留**安全操作**（暂停/停止/急停），并非完全只读；②"扫描唯一码"为增强
> 交互（App 扫码，P2），先做输入唯一码。

## 5. 内网 / 外网 边界细则

| 维度 | 内网（同 Wi-Fi） | 外网（4G/异地） |
|------|----------------|----------------|
| 控制 | 直连 TCP:8899 全功能（Jog/回零/开切） | 经② MQTT，**监视模式**（锁 Jog/开切） |
| 状态 | 直连 5–10Hz | 经② 1–5Hz |
| 视频 | 直连 RTSP（200–500ms） | 经① WebRTC/HLS |
| 模型库/任务/材质/账号 | 经②（方案 A） | 经② |
| G-code | ②/局域网服务直推机器 | ② 直推机器 |
| 断外网 | 控制+状态+RTSP 完整可用（模型库/任务同步受限） | 不可用（依赖云端） |
| 判定/鉴权 | 按**机器唯一码**匹配（mDNS/手动 IP 发现） | 唯一码 + Token/证书登录② |

## 12. 术语表

| 术语 | 含义 |
|------|------|
