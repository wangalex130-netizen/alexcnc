## 四、刀具推荐规则（已设计，待驱动配套后启用）

> 2026-08-08 讨论确认：驱动当前"先选刀具"流程**不算错误，偏专业向**；App Step3 可改刀兜底，故不阻塞。
> 推荐引擎规则我方已备好，驱动做"用途向导"（D2）时直接复用：

- **规则一（策略 → 刀型）**：粗加工→平底刀；精加工（浮雕收光）→球头刀；刻线/雕刻→V 型刀/尖刀；轮廓切割→平底刀（或螺旋刀）。
- **规则二（特征尺寸 → 刀径）**：刀径 ≤ 最小特征（最窄槽/最小圆角/最小间隙）× 0.6；粗加工按加工面积取大/小刀。
- **规则三（材质 → 修正）**：亚克力→单刃螺旋防熔；铝→2 刃螺旋/1/8 平底；木→通用。
- **输出**：有序工序刀具 `requiredTools`（粗雕→精雕→刻线）；**推荐 = 预填不强制**，客户在 App 向导 Step3 可改（映射物理刀兜）。
- **配套刀具库**：现有 7 把（3.175 平底 / 60° V / 1.5 球头 / 0.8 尖刀 / 亚克力单刃 / 铝 2 刃 / 1/8 平底）。
